## Аннотация
«Управление ключами для спутниковой связи на основе схем распределения секрета»

Проект посвящён защите сессионных ключей в LEO-созвездиях, где спутник виден 6–12 минут, а сессия постоянно передаётся между узлами. Проблема: компрометация одного спутника не должна раскрывать сессию, доверие должно быть распределённым.

Реализуем управление ключами на основе схем разделения секрета: ключ разбивается на n долей по Шамиру и раздаётся спутникам, восстановление — только при сборке k долей. Для сравнения — Блэкли и (N, N)-схема, анализ по размеру доли, времени, стойкости. Модель LEO-созвездия, шифрование AES-GCM. В работе также реализуются proactive refresh (обновление долей обнуляет многолетний сбор), VSS (ловит злого дилера), динамическое k (порог под обстановку) и пороговая подпись. Демонстрируются атаки: компрометация m спутников, злой дилер, накопление долей, подмена, replay.

Визуализация: интерактивная анимация на matplotlib.animation — спутники летают по орбитам, доли раздаются, ключ собирается, атаки показываются красным, успешные операции — зелёным. Плюс набор статичных графиков: ступенька компрометации, «зубчатая пила» proactive refresh, сравнение трёх схем, динамика k.

Результат: симуляция на Python с анимацией и графиками, сравнительный анализ трёх схем, метрики стойкости и производительности.

### Предварительные требования

Перед началом убедитесь, что у вас установлены:
- **Git** - для клонирования репозитория
- **Python** - для работы с проектом
- **uv** - современный менеджер пакетов для Python

### Шаг 1: Клонирование репозитория

Клонируем репозиторий
```bash
git clone git@github.com:stive-shipilov/satellite-key-management.git
cd satellite-key-management
```
### Шаг 2: Запуск окружения

Создание виртуального окружения и установка зависимостей

Если не установлен uv, то предварительно нужно его установить
```bash
pip install uv
```
Дальше переходим в директорию склонированного проекта и устанавливаем зависимости
```bash
uv sync
```

Активация виртуального окружения

```bash
source .venv/bin/activate  # Linux/macOS
```
```bash
.venv\Scripts\activate     # Windows
```
### Шаг 3: Запуск тестов и Jupiter Notebook

Запуск тестов
```bash
uv run pytest
```

Запуск Jupyter
```bash
uv run jupyter notebook
```
